# Algoritmi di Processing con AI

## Introduzione

I QGIS Processing Tools forniscono un'interfaccia standardizzata per algoritmi geografici e di analisi. In questo capitolo imparerai come creare algoritmi di processing che sfruttano l'Intelligenza Artificiale, integrandoli perfettamente nel workflow di QGIS.

## Esercizi

### Esercizio 1: Regressione lineare
Crea un algoritmo di processing che applica regressione lineare per prevedere un valore continuo

### Esercizio 2: Detección di outlier
Implementa un algoritmo che usa Isolation Forest per rilevare anomalie

### Esercizio 3: Classificazione multi-classe
Sviluppa un algoritmo che classifica feature in più categorie usando SVM

# Script da Console QGIS

## Introduzione

La console Python integrata in QGIS è uno strumento potente per eseguire script geografici direttamente nell'ambiente. In questo capitolo imparerai a scrivere script Python che sfruttano librerie AI per analizzare e manipolare dati geografici.

## Accedere alla Console Python

Per aprire la console Python in QGIS:

1. Vai a **Plugins** → **Python Console** (o premi `Ctrl + Alt + P`)
2. La console si aprirà in basso sullo schermo
3. Vedrai due pannelli: uno per l'editor e uno per l'output

## Esercizi

### Esercizio 1: Calcolo della densità di punti
Crea uno script che calcola la densità di punti in aree circolari usando KMeans

### Esercizio 2: Classificazione di feature
Usa scikit-learn per classificare feature vettoriali basandoti su attributi

### Esercizio 3: Previsione di valori
Applica regressione lineare per prevedere un valore basato su altri attributi
